Perfect ✅ Here is your exact step-by-step update process.

🟢 🔧 Updating Backend (Render + Bitbucket)
1️⃣ Make changes in VS Code

Edit backend code.

2️⃣ Push to Bitbucket

From project root:

git add .
git commit -m "update backend features"
git push
3️⃣ Deploy on Render

Go to:

Render → Your Backend Service

If Auto Deploy ON → it redeploys automatically.

If not:

Click → Manual Deploy → Deploy latest commit

✅ Backend updated.

🔵 🎨 Updating Frontend (Manual Netlify Deploy)
1️⃣ Make changes in VS Code

Edit frontend code.

2️⃣ Build again
cd frontend
npm run build

This updates the dist folder.

3️⃣ Upload to Netlify

Go to Netlify → Deploys
Drag & drop the NEW dist folder.

✅ Frontend updated.

⚡ Full Update Flow (Both)

Change code

Push backend → Render deploy

Rebuild frontend

Upload new dist

Done 🚀
